# ❤️ Lembre por Mim - Momentos em Família

**Menos tela. Mais presença. Mais vida.**

PWA completo com:
- 🔔 Lembretes com app fechado (notificação + som + vibração + voz)
- 🎙️ Microfone sem repetir (continuous=false)
- ❤️ Momentos em Família (Crianças/Adolescentes/Adultos > Em casa/Ao ar livre > 10/20/30+ min)
- 🌱 Um minuto de esperança: 150+ Salmos e Provérbios
- 📸 Nossos Momentos, 📊 Resumo, 👤 Perfil com foto

## Rodar local
python -m http.server 8000
Abrir http://localhost:8000

## Deploy GitHub Pages
1. Criar repo `lembre-por-mim` no GitHub
2. Upload dos arquivos deste ZIP
3. Settings > Pages > Branch: main / root > Save
4. Link: https://SEU_USUARIO.github.io/lembre-por-mim/

Deploy automático via Actions já incluso.
